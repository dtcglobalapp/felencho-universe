# Felencho Forever Engine

## Principio central

LiveAvatar es el cuerpo.
Felencho Forever es el cerebro.
El Studio Engine es el director del espacio donde viven los personajes.

## Capas principales

### 1. Felencho Brain
Guarda conocimiento, memoria, personalidad, relaciones y contexto.

### 2. Felencho Gateway
Conecta cualquier cuerpo con el Brain:
- LiveAvatar
- web
- móvil
- robot
- realidad aumentada
- estudio virtual

### 3. Presence System
Controla si un personaje está:
- en modo presence
- en modo live
- sleeping
- waking
- thinking
- speaking

### 4. Studio System
Controla estudios completos:
- new_york_physical
- felencho_virtual_studio
- mobile_director
- museum
- future_client_studios

### 5. Terminal System
Cada pantalla, app, robot o dispositivo es una terminal.
Ejemplos:
- Bob Terminal
- Lina Terminal
- Felencho Terminal

### 6. Director AI
Coordina escenas, turnos, temas, imágenes, videos, comentarios y ritmo del programa.

## Estudios principales

### New York Physical Studio
Estudio físico con pantallas, cámaras, micrófonos, consola y dirección manual o automática.

### Felencho Virtual Studio
Estudio digital donde Bob, Lina y Felencho Virtual pueden crear contenido sin que Felencho humano esté físicamente en New York.

## Regla de oro

Nunca conectar un personaje directamente a un servicio externo.

Siempre usar capas:

Character
↓
Presence
↓
Studio
↓
Gateway
↓
Brain
↓
Adapter externo

## Objetivo

Crear seres digitales capaces de habitar múltiples cuerpos sin reescribir el Brain.
